# ADA skills

Short, generic skills ADA uses. Project-specific skills (how to run a particular project's stack, its
review bot, its wiki, and so on) live in that Program's `.pam/`, not here. Generic ADA stays project
agnostic.

- `placeholders.md`: the complete list of placeholders a Program binds, and the rule that a command
  slot takes a placeholder or a literal, never a prose description.
- `worktree-setup.md`: create one isolated worktree and branch per issue, and tear it down safely
  after merge.
- `adversarial-review.md`: the blind subagent review ADA runs before marking a PR ready.
